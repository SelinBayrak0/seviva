### Project Description
Seviva is a simple e-commerce website built with **ReactJS**. It was created for the **Web Programming** course. The project allows users to browse products, add items to the cart, and manage their shopping experience easily.

## Installation & Setup
* Download the project files to your computer.
* Open the terminal inside the project folder.
* Run `npm install` to restore the node_modules folder.
* Run `npm start` to open the project in your web browser.
